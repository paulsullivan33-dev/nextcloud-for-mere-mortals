A second account, made from the command line. Note the
--password-from-env flag: without it, occ stops and asks
interactively, which hangs a script (chapter 15).

$ OC_PASS='<redacted>' php occ user:add --password-from-env \
    --display-name="Theo Marchetti" --email=theo@example.com theo
The account "theo" was created successfully
Display name set to "Theo Marchetti"
Welcome email sent to theo@example.com
(the welcome mail goes nowhere in this lab — there is no
mail server; the account works regardless)
